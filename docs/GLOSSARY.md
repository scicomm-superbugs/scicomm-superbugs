# Biotechnology & Computational Biology Glossary

- **PCR (Polymerase Chain Reaction)**: Molecular technique used to amplify specific DNA sequences.
- **Plasmid Vector**: Small, circular DNA molecule used in recombinant cloning.
- **Graph Coloring**: Algorithmic problem used to compute conflict-free academic timetables.
- **Turnstile Authentication**: Ephemeral QR-based verification protocol for student field access.
